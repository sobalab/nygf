# New York Garden Flower Wholesale

Responsive website scaffold for New York Garden Flower Wholesale, Inc.

## Start locally

1. Install Node.js 22 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address printed in the terminal.

## Production build

Run `npm run build`.

The primary site is in `app/page.tsx` and `app/globals.css`. A server-free review copy is included in `preview/index.html`.

The catalogue is inquiry-only. Prices are intentionally omitted because they change with the wholesale market.
